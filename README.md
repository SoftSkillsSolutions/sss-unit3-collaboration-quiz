# SSS — Unité 3 : Collaboration

Autoévaluation interactive en français canadien : **Êtes-vous un bon coéquipier?**

Le site est entièrement statique (HTML/CSS/JavaScript). Il ne demande aucun nom ni courriel et n’enregistre pas les réponses des participants.

## Fichiers du site

- `index.html` — page du quiz
- `styles.css` — mise en page et style visuel
- `quiz.js` — 10 situations, rétroaction et calcul du bilan
- `skillforce-logo.png` — logo officiel fourni par Simcoe Muskoka Skillforce

## Publication avec GitHub Pages

1. Ajouter le fichier du logo fourni sous le nom exact `skillforce-logo.png` à la racine du dépôt.
2. Ouvrir **Settings > Pages**.
3. Sous **Build and deployment**, choisir **Deploy from a branch**.
4. Choisir la branche **main** et le dossier **/(root)**.
5. Cliquer sur **Save**.

Lien public prévu :

`https://softskillssolutions.github.io/sss-unit3-collaboration-quiz/`

Une fois GitHub Pages activé, le lien peut être placé directement dans le cahier de l’Unité 3. Aucun compte GitHub ni mot de passe n’est requis pour les participants.
